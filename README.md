🎮 Rock Paper Scissors Web App
A simple, interactive Rock‑Paper‑Scissors game built with Python and Streamlit. The goal is to be the first to reach 5 points against the computer. This project started as a terminal‑based Python script and was upgraded into a clean, browser‑based web application.

🚀 Features
- Play Rock, Paper, Scissors directly in your browser
- Clean and interactive UI powered by Streamlit
- Real‑time score tracking using Streamlit session state
- Randomized computer choices
- Win/lose messages when either player reaches 5 points

🧠 How It Works
The app uses:
- Streamlit for the web interface
- Python’s random module to generate computer moves
- Session state to track scores across rounds
Each round:
- You select Rock, Paper, or Scissors
- The computer randomly selects a move
- The app determines the winner
- Scores update until someone reaches 5
